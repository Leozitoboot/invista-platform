# inVista Platform

Plataforma de investimentos imobiliários globais — protótipo navegável (P0.x).

## Stack
- Vite + React + TypeScript
- React Router v6
- Tailwind CSS v3
- react-i18next
- Playwright + Axe (a11y)

## Rodar localmente
```bash
npm install
npm run dev
```

## Testes de acessibilidade
```bash
npm run test:a11y
```

## Sprints
- **P0.1** — Protótipo navegável (jornada completa, dados mock)
- **P0.2** — i18n + Design System + Telemetria
- **P0.3** — Branding real inVista + Liquid Glass + Light/Dark + QA Gate WCAG 2.1 AA
